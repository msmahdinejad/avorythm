## پیش‌نیازها

- ویندوز ۱۰ یا ۱۱ نسخهٔ ۶۴ بیتی
- Chrome یا Edge نسخهٔ ۱۱۶ به بالا
- API Key با دسترسی به `gemini-3.5-live-translate-preview`
- اینترنت و در صورت نیاز پروکسی HTTP مثل `http://127.0.0.1:10808`

## نصب Companion

1. `LingoDub-Setup-x64.exe` را از Releases دانلود و نصب کن.
2. برنامه را اجرا کن؛ داشبورد خودکار باز می‌شود.
3. از تنظیمات پیشرفته، API Key را وارد و ذخیره کن.
4. آدرس پروکسی را تنظیم کن؛ برای اتصال مستقیم خالی بگذار.

کلید در Windows Credential Manager ذخیره می‌شود و داخل `settings.json` نیست. توسعه‌دهنده‌ها می‌توانند از `.env` هم استفاده کنند؛ این فایل وارد Git نمی‌شود.

## نصب اکستنشن

1. `LingoDub-Extension.zip` را در یک مسیر ثابت Extract کن.
2. `chrome://extensions` یا `edge://extensions` را باز کن.
3. Developer mode را روشن کن.
4. Load unpacked را بزن و همان پوشه را انتخاب کن.
5. اکستنشن را Pin کن.

اکستنشن فقط تبی را Capture می‌کند که خودت روی آن Start زده‌ای. بعد از Capture، پخش مستقیم تب متوقف می‌شود و LingoDub صدا را مطابق حالت انتخابی بازسازی می‌کند؛ به همین دلیل در حالت «فقط دوبله» صدای اصلی روی دوبله نمی‌افتد.

## تنظیم خودکار صدای برنامه‌های ویندوز

برنامه‌ای مثل VLC صدایش را مستقیم به خروجی ویندوز می‌فرستد. برای جداسازی آن:

1. یک Virtual Audio Device معتبر مثل VB-CABLE نصب کن یا از دستگاه مجازی فعلی استفاده کن.
2. داخل LingoDub «راه‌اندازی خودکار صدا» را بزن؛ ورودی مجازی و هدفون تشخیص داده می‌شوند.
3. «باز کردن میکسر صدای ویندوز» را بزن.
4. خروجی VLC یا Player را روی دستگاه مجازی قرار بده.
5. خروجی LingoDub را هدفون واقعی بگذار.
6. صدای اصلی را ۰٪ و دوبله را ۱۰۰٪ تنظیم کن.

نصب خودکار Driver عمداً انجام نمی‌شود: ویندوز دسترسی Administrator و تأیید اعتماد Driver می‌خواهد و انتخاب Driver شخص ثالث باید با خود کاربر باشد. برنامه تشخیص و تنظیمات داخلی را خودکار می‌کند و صفحهٔ لازم ویندوز را باز می‌کند.

## رفع مشکل

- **Companion آفلاین است:** `LingoDub.exe` را اجرا کن.
- **ترجمه نمی‌آید:** دسترسی مدل، Key، سهمیه و پروکسی را بررسی کن.
- **صدای تب نمی‌آید:** نسخهٔ مرورگر حداقل ۱۱۶ باشد و هنگام Start همان تب فعال باشد. صفحات DRM ممکن است Capture را مسدود کنند.
- **Echo در برنامهٔ دسکتاپ:** ورودی Capture و خروجی دوبله نباید یک Device باشند.
- **گویندهٔ انتخابی تأخیر دارد:** گوینده‌های نام‌دار یک مرحلهٔ TTS اضافه دارند؛ برای کمترین تأخیر `Native` را بگذار.
