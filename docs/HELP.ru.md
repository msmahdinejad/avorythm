# Руководство Avorythm

[English](HELP.md) · [فارسی](HELP.fa.md) · [简体中文](HELP.zh-CN.md) · [Конфиденциальность](../PRIVACY.md)

Avorythm состоит из двух независимых продуктов: настольного приложения для программ и локальных файлов и расширения Chrome/Edge, которое переводит только явно выбранную вкладку. Расширению не нужны приложение, Python, FFmpeg или localhost.

## Языки и приватность

Доступны английский, персидский, арабский, упрощённый и традиционный китайский, немецкий, французский, итальянский, испанский, русский, японский, корейский, турецкий, португальский, нидерландский, польский, украинский, хинди, урду, иврит, индонезийский, малайский, вьетнамский, тайский и другие языки. Ключи Google и Groq по умолчанию хранятся только в сессии браузера; запись выключена. Avorythm не отправляет содержимое сопровождающему проекта и не использует рекламу или аналитику.

## Настольное приложение

1. Скачайте сборку со страницы [Releases](https://github.com/msmahdinejad/avorythm/releases). В установщик Windows уже входит FFmpeg.
2. Откройте Advanced settings, добавьте ключ Gemini. Для файлового режима добавьте ключ Groq Whisper.
3. Для перевода VLC или другой программы в реальном времени направьте её звук на loopback/monitor и выберите этот источник в Avorythm. Для загруженных файлов виртуальное устройство не нужно.
4. В File Studio выберите язык, голос и режим **Precise sync** или **Fast**. После обработки доступны `original.wav`, `dubbed.wav`, `source.srt` и `translated.srt`.

Оригинальный звук, дубляж, исходные и переведённые субтитры независимы: их можно комбинировать, менять громкость и открывать перемещаемое окно субтитров.

## Расширение браузера

Установите [Avorythm из Chrome Web Store](https://chromewebstore.google.com/detail/avorythm-live-translation/kbdbbedijheicmmmoidamdaodjbhjje) или включите Developer mode на `chrome://extensions` и выберите Load unpacked после распаковки ZIP.

При первом запуске откройте Settings, введите ключ Gemini и явно подтвердите отправку аудио выбранной вкладки в Google Gemini. Выберите язык и режим:

- **On this page** — минимальная задержка для живого перевода.
- **Synchronized recorder & player** — запись с опережением, поиск, пауза, полноэкранный режим и экспорт.

Четыре канала можно включать независимо. Запись начинается только после включения опции и нажатия Start.

Если возникла проблема, прочитайте [полную английскую инструкцию](HELP.md) или создайте [Issue](https://github.com/msmahdinejad/avorythm/issues), приложив шаги воспроизведения и логи.
