# دليل Avorythm

[English](HELP.md) · [فارسی](HELP.fa.md) · [简体中文](HELP.zh-CN.md) · [الخصوصية](../PRIVACY.md)

Avorythm منتجان مستقلان: تطبيق سطح مكتب للبرامج والملفات المحلية، وإضافة Chrome/Edge تترجم علامة التبويب التي تختارها صراحةً. الإضافة لا تحتاج إلى التطبيق أو Python أو FFmpeg أو localhost.

## اللغات والخصوصية

يمكن اختيار العربية والإنجليزية والفارسية والصينية المبسطة/التقليدية والألمانية والفرنسية والإيطالية والإسبانية والروسية واليابانية والكورية والتركية والبرتغالية والهندية والأردية والعبرية والإندونيسية والماليزية والفيتنامية والتايلاندية ولغات إضافية. مفاتيح Google وGroq تبقى في جلسة المتصفح افتراضياً؛ التسجيل متوقف افتراضياً. لا يرسل Avorythm المحتوى إلى المطوّر ولا يحتوي على إعلانات أو تحليلات.

## تطبيق سطح المكتب

1. نزّل إصدار نظامك من [Releases](https://github.com/msmahdinejad/avorythm/releases) وشغّله. مثبت Windows يتضمن FFmpeg.
2. افتح الإعدادات المتقدمة وأدخل مفتاح Gemini. لمعالجة الملفات أضف مفتاح Groq Whisper.
3. للترجمة الحية من VLC أو برنامج آخر، وجّه صوت البرنامج إلى جهاز loopback/monitor ثم اختره كمدخل Avorythm. معالجة الملفات لا تحتاج إلى جهاز افتراضي.
4. في استوديو الملفات اختر اللغة والصوت ووضع **Precise sync** أو **Fast**. بعد المعالجة تحصل على `original.wav` و`dubbed.wav` و`source.srt` و`translated.srt`.

يمكن مزج الصوت الأصلي والدبلجة وكل مسارَي الترجمة بشكل مستقل، مع تغيير مستوى الصوت وفتح نافذة ترجمة عائمة قابلة للتحريك وتغيير الحجم.

## إضافة المتصفح

ثبّت الإضافة من [Chrome Web Store](https://chromewebstore.google.com/detail/avorythm-live-translation/kbdbbedijheicmmnmoidamdaodjbhjje)، أو فعّل Developer mode في `chrome://extensions` واختر Load unpacked بعد فك الحزمة.

في أول تشغيل افتح Settings وأدخل مفتاح Gemini ووافق صراحةً على إرسال صوت علامة التبويب المحددة إلى Google Gemini. اختر اللغة ثم أحد الوضعين:

- **On this page**: أقل تأخير للصوت والترجمة.
- **Synchronized recorder & player**: تسجيل مسبق يتيح البحث والتقديم والتأخير وملء الشاشة والتصدير.

المسارات الأربعة مستقلة: الصوت الأصلي، صوت الدبلجة، ترجمة المصدر، والترجمة العربية/المستهدفة. التسجيل لا يبدأ إلا بعد الضغط على Start وتفعيله.

للمشكلات راجع [الدليل الإنجليزي](HELP.md) أو افتح [Issue](https://github.com/msmahdinejad/avorythm/issues) مع خطوات إعادة الإنتاج وسجل وحدة التحكم.
