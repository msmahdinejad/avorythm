مراحل تنظیم Windows

اول برنامهٔ مقصد را باز کن و چند ثانیه صدا پخش کن تا در Volume Mixer نمایش داده شود.

  1. ۱اگر Virtual Cable نداری، یک درایور معتبر مثل VB-CABLE رسمی نصب و Windows را Restart کن.
  2. ۲Settings → System → Sound → Volume mixer را باز کن.
  3. ۳در بخش Apps، خروجی فقط برنامهٔ فیلم یا دوره را روی CABLE Input بگذار.
  4. ۴در داشبورد LingoDub، «ورودی صدای برنامه» را روی Loopback همان Virtual Cable بگذار.
  5. ۵«خروجی شنیداری» LingoDub را هدفون/اسپیکر واقعی انتخاب کن؛ صدای اصلی ۰٪ و دوبله ۱۰۰٪.
مهم: خروجی خود LingoDub را روی Virtual Cable نگذار؛ این کار حلقهٔ صوتی و اکو ایجاد می‌کند.

Windows setup

Open the source app and play audio for a few seconds so it appears in Volume Mixer.

  1. 1If needed, install a trusted device such as the official VB-CABLE, then restart Windows.
  2. 2Open Settings → System → Sound → Volume mixer.
  3. 3Under Apps, set the output of only the movie/course player to CABLE Input.
  4. 4In LingoDub, select that Virtual Cable loopback as Application audio input.
  5. 5Select physical headphones as Listening output; set Original to 0% and Dubbed to 100%.
Important: never send LingoDub's own output to the Virtual Cable. That creates an audio feedback loop.
