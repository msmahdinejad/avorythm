AVORYTHM / GUIDE

Everything you need, from first launch to a synchronized recording.

The desktop app and browser extension are independent. Choose the section that matches what you installed.

Set up the app ↓Set up the extension ↓
01

Desktop app

For live desktop audio and uploaded audio/video files.

1

Install and add keys

Windows already includes FFmpeg. Open Advanced settings and save Gemini and Groq keys.

2

Choose what you hear

Original audio, dubbed audio, source captions, and translated captions are independent.

3

Route live desktop audio

Only live translation from another desktop program needs a loopback device.

4

Process a media file

Drop audio or video into File Studio and download the synchronized outputs.

02

Browser extension

Standalone tab translation—no desktop app, FFmpeg, localhost, or virtual cable.

1

Complete the required consent

Open Settings, add the key, and confirm selected-tab audio consent.

2

Choose a playback path

Choose low latency or synchronized recording.

3

Choose the synchronized engine

Choose the fast or precise synchronized engine.

4

Record, seek, and export

The source records ahead; the player can pause, seek, fullscreen, and export.

Important

Fullscreen the Avorythm player for translated playback.
