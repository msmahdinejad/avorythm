# Chrome Web Store — Korean (ko)

## 이름

Avorythm — AI 실시간 더빙 및 자막

## 짧은 설명

AI로 선택한 탭의 오디오를 번역하세요. 실시간 더빙, 이중 언어 자막, 동기화된 플레이어를 제공합니다.

## 상세 설명

강의, 동영상, 영화를 시청하거나 팟캐스트를 원하는 언어로 들어보세요. Avorythm은 사용자가 명시적으로 선택한 브라우저 탭의 오디오를 AI로 번역합니다. 실시간 더빙 음성을 듣고 원문과 번역 자막을 함께 보거나, 원본 오디오를 유지하면서 번역 자막만 읽을 수 있습니다.

원래 페이지에서 지연을 줄여 재생하거나, 동기화된 녹화 및 플레이어 기능을 이용하세요. 동기화 모드에서는 캡처가 재생보다 앞서 진행되며, 별도 플레이어에서 일시정지, 탐색, 전체 화면 기능을 사용할 수 있습니다. 녹화는 수동으로 종료할 수 있습니다.

원본 오디오, 더빙 오디오, 원문 자막, 번역 자막의 네 가지 채널을 각각 제어할 수 있습니다. 두 오디오의 음량을 조절하고 자막 오버레이의 위치와 크기를 변경하며, 설정에 맞춘 WebM 동영상과 별도의 SRT 자막을 내보낼 수 있습니다. 일반 녹화를 선택하면 두 오디오 트랙을 각각 WAV로, 두 자막 트랙을 각각 SRT로 저장할 수도 있습니다.

이 확장 프로그램은 데스크톱 앱, Python, FFmpeg, localhost 또는 가상 오디오 장치 없이 독립적으로 작동합니다. 현재 인터페이스는 영어, 페르시아어, 중국어 간체만 지원합니다. 번역 대상 언어는 별도로 제공되는 79개 언어 항목 중에서 선택합니다.

설정 방법: 설정에서 Google AI Studio를 통해 발급받은 본인의 Gemini API 키를 입력하고, 선택한 탭의 오디오를 Google Gemini로 전송하는 데 명시적으로 동의한 다음 언어를 선택하고 시작을 누르세요. 선택 사항인 정밀 모드는 Groq Whisper로 음성을 전사하고, Gemini로 텍스트를 번역하며, Gemini 3.1 Flash Live로 음성을 생성합니다. 이 모드에는 Groq 키, 선택적 호스트 권한, 별도의 오디오 전송 동의가 필요합니다.

개인정보 보호: 캡처는 동의한 뒤 시작을 눌러야만 시작됩니다. 선택한 탭의 오디오와 전사된 텍스트는 요청한 처리에 필요한 AI 제공업체로 직접 전송되며, Avorythm 개발자에게는 전송되지 않습니다. 광고, 분석 기능 또는 개발자가 운영하는 중계 서버는 없습니다.

API 키는 기본적으로 현재 세션에만 보관됩니다. 각 제공업체의 키를 이 기기에 기억하도록 설정하는 기능은 개별적으로 선택할 수 있으며, 기본적으로 꺼져 있습니다. 기기에 저장된 키는 동기화되지 않으며 확장 프로그램이 암호화하지도 않습니다. 기억 설정을 끄면 기기에 저장된 키가 삭제되고, 키를 지우면 기기와 세션에 보관된 사본이 모두 삭제됩니다.

네 가지 출력을 저장하는 일반 녹화 기능은 기본적으로 꺼져 있습니다. 동기화 모드는 재생과 내보내기를 위해 로컬에서 녹화하며, Chrome의 비공개 저장소에는 가장 최근 캡처만 보관합니다. 다운로드한 파일은 Downloads/Avorythm에 저장됩니다.

Avorythm은 무료 오픈 소스입니다. 외부 AI 서비스의 무료 사용 한도와 모델 제공 여부는 변경될 수 있습니다. 실시간 처리에는 네트워크 통신 시간이 필요하므로 지연이 전혀 없거나 번역이 완벽하다고 보장하지 않습니다. 중요한 내용은 확인하세요. DRM으로 보호된 미디어와 브라우저 내부 페이지에서는 캡처가 불가능할 수 있습니다.
