# Chrome Web Store — Traditional Chinese (zh-Hant)

## 名稱

Avorythm — AI 即時配音與字幕

## 簡短說明

為你選取的分頁提供 AI 翻譯：即時配音、雙語字幕，以及同步播放器。

## 詳細說明

用自己的語言觀看課程、影片和電影，或收聽播客。Avorythm 使用 AI 翻譯你明確選取的瀏覽器分頁音訊。你可以聆聽即時配音、查看原文與譯文字幕，或保留原音，只閱讀翻譯。

你可以選擇在原網頁上以低延遲播放，或使用同步錄製與播放器。同步擷取會提前處理內容，獨立播放器則可暫停、跳轉進度及全螢幕播放。你也可以手動結束錄製。

四個聲音與字幕通道可分別控制：原音、配音、原文字幕及譯文字幕。你可以調整兩種音訊的音量、移動和縮放字幕疊加層，並匯出自訂的 WebM 影片及獨立的 SRT 字幕。啟用選用的一般錄製功能後，也能將兩條音軌分別儲存為 WAV，並將兩條字幕軌分別儲存為 SRT。

此擴充功能可獨立運作，無需桌面應用程式、Python、FFmpeg、localhost 或虛擬音訊裝置。目前介面僅支援英文、波斯文及簡體中文；翻譯的目標語言則可另外從 79 個語言選項中選擇。

設定方式：在設定中輸入你自行從 Google AI Studio 取得的 Gemini API 金鑰，明確同意將所選分頁的音訊傳送至 Google Gemini，選擇語言，然後按下「Start」。選用的精確模式使用 Groq Whisper 進行語音轉錄、Gemini 進行文字翻譯，並使用 Gemini 3.1 Flash Live 產生語音。此模式需要 Groq 金鑰、選用的主機權限，以及另行取得的音訊傳送同意。

隱私：只有在你同意並按下「Start」後，才會開始擷取。所選分頁的音訊和逐字稿會直接傳送至處理你所要求內容所需的 AI 服務提供者，絕不會傳送給 Avorythm 的維護者。沒有廣告、分析追蹤或由開發者營運的中繼伺服器。

API 金鑰預設僅在工作階段期間保留。是否在此裝置上記住各服務提供者的金鑰可分別選擇，預設為關閉。擴充功能不會同步或加密儲存的副本。關閉記住金鑰會刪除裝置上的副本；清除金鑰則會同時刪除裝置與工作階段中的副本。

一般四項輸出錄製功能預設為關閉。同步模式會在本機錄製，以供播放與匯出，並且只會在 Chrome 的私人儲存空間保留最近一次擷取的內容。下載的檔案會存放在 Downloads/Avorythm。

Avorythm 免費且開放原始碼。外部 AI 服務的免費額度與模型供應情況可能變動。即時處理需要網路傳輸時間，不保證零延遲或翻譯完全正確；請核對重要內容。受 DRM 保護的媒體及瀏覽器內部頁面可能無法擷取。
