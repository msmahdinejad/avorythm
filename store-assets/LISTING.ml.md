# Chrome Web Store — Malayalam (ml)

## പേര്

Avorythm — AI തത്സമയ ഡബ്ബിങ്ങും സബ്‌ടൈറ്റിലുകളും

## ഹ്രസ്വ വിവരണം

നിങ്ങൾ തിരഞ്ഞെടുത്ത ടാബിലെ ശബ്ദത്തിന് AI വിവർത്തനം: തത്സമയ ഡബ്ബിങ്, ദ്വിഭാഷാ അടിക്കുറിപ്പുകൾ, സമന്വയിപ്പിച്ച പ്ലെയർ.

## വിശദമായ വിവരണം

കോഴ്സുകളും വീഡിയോകളും സിനിമകളും നിങ്ങളുടെ ഭാഷയിൽ കാണുക, അല്ലെങ്കിൽ പോഡ്‌കാസ്റ്റുകൾ കേൾക്കുക. നിങ്ങൾ വ്യക്തമായി തിരഞ്ഞെടുക്കുന്ന ബ്രൗസർ ടാബിലെ ശബ്ദം വിവർത്തനം ചെയ്യാൻ Avorythm AI ഉപയോഗിക്കുന്നു. തത്സമയം ഡബ്ബ് ചെയ്ത സംസാരം കേൾക്കാം, മൂലഭാഷയിലെയും വിവർത്തനം ചെയ്തതുമായ അടിക്കുറിപ്പുകൾ കാണാം, അല്ലെങ്കിൽ യഥാർത്ഥ ശബ്ദം നിലനിർത്തി വിവർത്തനം മാത്രം വായിക്കാം.

യഥാർത്ഥ പേജിൽ കുറഞ്ഞ കാലതാമസമുള്ള പ്ലേബാക്കോ സമന്വയിപ്പിച്ച റെക്കോർഡറും പ്ലെയറോ തിരഞ്ഞെടുക്കാം. സമന്വയിപ്പിച്ച റെക്കോർഡിങ് പ്ലേബാക്കിനെക്കാൾ മുന്നേ നടക്കുമ്പോൾ, സ്വതന്ത്ര പ്ലെയറിൽ താൽക്കാലികമായി നിർത്താനും ആവശ്യമുള്ള ഭാഗത്തേക്ക് നീങ്ങാനും പൂർണ്ണസ്ക്രീനിൽ കാണാനും കഴിയും. റെക്കോർഡിങ് നിങ്ങൾക്ക് നേരിട്ട് അവസാനിപ്പിക്കാം.

നാല് ഘടകങ്ങൾ വെവ്വേറെ നിയന്ത്രിക്കാം: യഥാർത്ഥ ശബ്ദം, ഡബ്ബ് ചെയ്ത ശബ്ദം, മൂലഭാഷയിലെ സബ്‌ടൈറ്റിലുകൾ, വിവർത്തനം ചെയ്ത സബ്‌ടൈറ്റിലുകൾ. രണ്ട് ശബ്ദങ്ങളുടെയും വോള്യം ക്രമീകരിക്കാം, അടിക്കുറിപ്പുകൾ കാണിക്കുന്ന ഭാഗം നീക്കുകയും വലുപ്പം മാറ്റുകയും ചെയ്യാം, ക്രമീകരിച്ച WebM വീഡിയോയും പ്രത്യേക SRT സബ്‌ടൈറ്റിലുകളും എക്‌സ്‌പോർട്ട് ചെയ്യാം. ഐച്ഛികമായ സാധാരണ റെക്കോർഡിങ്, രണ്ട് ശബ്ദ ട്രാക്കുകളും WAV ആയും രണ്ട് സബ്‌ടൈറ്റിൽ ട്രാക്കുകളും SRT ആയും സംരക്ഷിക്കും.

ഡെസ്‌ക്‌ടോപ്പ് ആപ്പോ Python, FFmpeg, localhost, വെർച്വൽ ഓഡിയോ ഉപകരണം എന്നിവയോ ഇല്ലാതെ തന്നെ ഈ എക്‌സ്‌റ്റൻഷൻ പ്രവർത്തിക്കും. നിലവിൽ ഇന്റർഫേസ് ഇംഗ്ലീഷ്, പേർഷ്യൻ, ലളിതീകരിച്ച ചൈനീസ് എന്നീ ഭാഷകളിലാണ്; വിവർത്തനത്തിനുള്ള ലക്ഷ്യഭാഷ 79 ഭാഷാ എൻട്രികളിൽനിന്ന് പ്രത്യേകം തിരഞ്ഞെടുക്കാം.

സജ്ജീകരണം: Google AI Studio-യിൽനിന്നുള്ള നിങ്ങളുടെ സ്വന്തം Gemini API കീ ക്രമീകരണങ്ങളിൽ നൽകുക, തിരഞ്ഞെടുത്ത ടാബിലെ ശബ്ദം Google Gemini-യിലേക്ക് അയയ്ക്കുന്നതിന് വ്യക്തമായ സമ്മതം നൽകുക, ഭാഷ തിരഞ്ഞെടുത്ത് Start അമർത്തുക. ഐച്ഛികമായ കൂടുതൽ കൃത്യതയുള്ള രീതിയിൽ ശബ്ദം ലിപ്യന്തരണം ചെയ്യാൻ Groq Whisper, പാഠം വിവർത്തനം ചെയ്യാൻ Gemini, സംസാരം സൃഷ്ടിക്കാൻ Gemini 3.1 Flash Live എന്നിവ ഉപയോഗിക്കുന്നു. ഇതിന് Groq കീയും ഐച്ഛിക ഹോസ്റ്റ് അനുമതിയും ശബ്ദത്തിനായി പ്രത്യേക സമ്മതവും ആവശ്യമാണ്.

സ്വകാര്യത: സമ്മതം നൽകി Start അമർത്തിയതിനുശേഷം മാത്രമേ ശബ്ദം പകർത്തൽ ആരംഭിക്കൂ. ആവശ്യപ്പെട്ട പ്രോസസ്സിങ്ങിന് വേണ്ട AI സേവനദാതാക്കളിലേക്കാണ് തിരഞ്ഞെടുത്ത ടാബിലെ ശബ്ദവും ലിപ്യന്തരണങ്ങളും നേരിട്ട് പോകുന്നത്; Avorythm-ന്റെ പരിപാലകനിലേക്ക് ഒരിക്കലും പോകില്ല. പരസ്യങ്ങളോ അനലിറ്റിക്‌സോ ഡെവലപ്പർ നടത്തുന്ന ഇടനില സെർവറോ ഇല്ല.

API കീകൾ സ്ഥിരസ്ഥിതിയായി നിലവിലെ സെഷനിൽ മാത്രമേ സൂക്ഷിക്കൂ. ഓരോ സേവനദാതാവിന്റെയും കീ ഈ ഉപകരണത്തിൽ ഓർത്തുവയ്ക്കുന്നത് വെവ്വേറെ തിരഞ്ഞെടുക്കാവുന്ന സൗകര്യമാണ്; സ്ഥിരസ്ഥിതിയായി അത് ഓഫാണ്. ഉപകരണത്തിൽ സൂക്ഷിക്കുന്ന പകർപ്പുകൾ സമന്വയിപ്പിക്കപ്പെടില്ല; എക്‌സ്‌റ്റൻഷൻ അവ എൻക്രിപ്റ്റ് ചെയ്യുകയുമില്ല. ഓർത്തുവയ്ക്കൽ ഓഫാക്കിയാൽ ഉപകരണത്തിലെ പകർപ്പ് ഇല്ലാതാകും; ഒരു കീ മായ്ച്ചാൽ ഉപകരണത്തിലെയും സെഷനിലെയും പകർപ്പുകൾ ഇല്ലാതാകും.

നാല് ഔട്ട്‌പുട്ടുകളുള്ള സാധാരണ റെക്കോർഡിങ് സ്ഥിരസ്ഥിതിയായി ഓഫാണ്. സമന്വയിപ്പിച്ച രീതി പ്ലേബാക്കിനും എക്‌സ്‌പോർട്ടിനുമായി ഉപകരണത്തിൽ തന്നെ റെക്കോർഡ് ചെയ്യുകയും ഏറ്റവും പുതിയ റെക്കോർഡിങ് മാത്രം Chrome-ന്റെ സ്വകാര്യ സംഭരണത്തിൽ സൂക്ഷിക്കുകയും ചെയ്യുന്നു. ഡൗൺലോഡ് ചെയ്യുന്ന ഫയലുകൾ Downloads/Avorythm-ലേക്ക് പോകും.

Avorythm സൗജന്യവും ഓപ്പൺ സോഴ്‌സുമാണ്. ബാഹ്യ AI സേവനങ്ങളുടെ സൗജന്യ ഉപയോഗപരിധികളും മോഡലുകളുടെ ലഭ്യതയും മാറാം. തത്സമയ പ്രോസസ്സിങ്ങിന് നെറ്റ്‌വർക്ക് സമയം ആവശ്യമാണ്; കാലതാമസം ഒട്ടും ഉണ്ടാകില്ലെന്നോ വിവർത്തനം പൂർണമായും കൃത്യമായിരിക്കുമെന്നോ ഉറപ്പില്ല. പ്രധാനപ്പെട്ട ഉള്ളടക്കം പരിശോധിച്ചുറപ്പിക്കുക. DRM പരിരക്ഷയുള്ള മീഡിയയും ബ്രൗസറിന്റെ ആഭ്യന്തര പേജുകളും ശബ്ദം പകർത്തുന്നത് തടഞ്ഞേക്കാം.

## 1.1.17-ലെ പുതുമകൾ

- ഭാഷ തിരഞ്ഞെടുക്കൽ എളുപ്പമാക്കി: ജനപ്രിയ ഭാഷകൾ ആദ്യം കാണിക്കുന്നു; ചൈനീസ്, പോർച്ചുഗീസ് ഭാഷകളുടെ വകഭേദങ്ങൾ വ്യക്തമായി വേർതിരിച്ചിരിക്കുന്നു.
- ജർമൻ, ഫ്രഞ്ച്, ഇറ്റാലിയൻ, റഷ്യൻ, അറബി ഭാഷകളിൽ പുതിയ പ്രോജക്റ്റ് രേഖകളും സഹായസാമഗ്രികളും.
- യഥാർത്ഥ ഉൽപ്പന്ന ഇന്റർഫേസിനെ അടിസ്ഥാനമാക്കിയുള്ള സ്റ്റോർ ചിത്രങ്ങൾ പുതുക്കി.
