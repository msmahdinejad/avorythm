# Chrome Web Store — Kannada (kn)

## ಹೆಸರು

Avorythm — AI ನೇರ ಡಬ್ಬಿಂಗ್ ಮತ್ತು ಉಪಶೀರ್ಷಿಕೆಗಳು

## ಸಂಕ್ಷಿಪ್ತ ವಿವರಣೆ

ನೀವು ಆಯ್ದ ಟ್ಯಾಬ್‌ಗೆ AI ಅನುವಾದ: ನೇರ ಡಬ್ಬಿಂಗ್, ದ್ವಿಭಾಷಾ ಉಪಶೀರ್ಷಿಕೆಗಳು ಮತ್ತು ಸಿಂಕ್ ಮಾಡಿದ ಪ್ಲೇಯರ್.

## ವಿವರವಾದ ವಿವರಣೆ

ಕೋರ್ಸ್‌ಗಳು, ವೀಡಿಯೊಗಳು ಮತ್ತು ಚಲನಚಿತ್ರಗಳನ್ನು ನಿಮ್ಮ ಭಾಷೆಯಲ್ಲಿ ನೋಡಿ ಅಥವಾ ಪಾಡ್‌ಕಾಸ್ಟ್‌ಗಳನ್ನು ಆಲಿಸಿ. ನೀವು ಸ್ಪಷ್ಟವಾಗಿ ಆಯ್ಕೆ ಮಾಡಿದ ಬ್ರೌಸರ್ ಟ್ಯಾಬ್‌ನ ಆಡಿಯೊವನ್ನು ಅನುವಾದಿಸಲು Avorythm AI ಬಳಸುತ್ತದೆ. ನೇರವಾಗಿ ಡಬ್ ಮಾಡಿದ ಮಾತನ್ನು ಕೇಳಿ, ಮೂಲ ಮತ್ತು ಅನುವಾದಿತ ಉಪಶೀರ್ಷಿಕೆಗಳನ್ನು ನೋಡಿ, ಅಥವಾ ಮೂಲ ಆಡಿಯೊವನ್ನು ಉಳಿಸಿಕೊಂಡು ಅನುವಾದವನ್ನು ಮಾತ್ರ ಓದಿ.

ಮೂಲ ಪುಟದಲ್ಲೇ ಕಡಿಮೆ ವಿಳಂಬದ ಪ್ಲೇಬ್ಯಾಕ್ ಅಥವಾ ಸಿಂಕ್ ಮಾಡಿದ ರೆಕಾರ್ಡರ್ ಮತ್ತು ಪ್ಲೇಯರ್ ಅನ್ನು ಆಯ್ಕೆಮಾಡಿ. ಸಿಂಕ್ ಮಾಡಿದ ಸೆರೆಹಿಡಿಯುವಿಕೆ ಮುಂದಾಗಿ ನಡೆಯುತ್ತದೆ; ಪ್ರತ್ಯೇಕ ಪ್ಲೇಯರ್‌ನಲ್ಲಿ ವಿರಾಮಗೊಳಿಸಬಹುದು, ಬೇಕಾದ ಭಾಗಕ್ಕೆ ಹೋಗಬಹುದು ಮತ್ತು ಪೂರ್ಣಪರದೆಯಲ್ಲಿ ವೀಕ್ಷಿಸಬಹುದು. ರೆಕಾರ್ಡಿಂಗ್ ಅನ್ನು ಕೈಯಾರೆ ಮುಗಿಸಬಹುದು.

ನಾಲ್ಕು ಚಾನೆಲ್‌ಗಳನ್ನು ಪ್ರತ್ಯೇಕವಾಗಿ ನಿಯಂತ್ರಿಸಿ: ಮೂಲ ಆಡಿಯೊ, ಡಬ್ ಮಾಡಿದ ಆಡಿಯೊ, ಮೂಲ ಉಪಶೀರ್ಷಿಕೆಗಳು ಮತ್ತು ಅನುವಾದಿತ ಉಪಶೀರ್ಷಿಕೆಗಳು. ಎರಡೂ ಆಡಿಯೊಗಳ ಧ್ವನಿಮಟ್ಟವನ್ನು ಬೆರೆಸಿ, ಉಪಶೀರ್ಷಿಕೆಗಳ ಮೇಲ್ಚಾಚನ್ನು ಸರಿಸಿ ಮತ್ತು ಅದರ ಗಾತ್ರ ಬದಲಿಸಿ, ಕಸ್ಟಮೈಸ್ ಮಾಡಿದ WebM ವೀಡಿಯೊ ಹಾಗೂ ಪ್ರತ್ಯೇಕ SRT ಉಪಶೀರ್ಷಿಕೆಗಳನ್ನು ರಫ್ತು ಮಾಡಿ. ಐಚ್ಛಿಕ ಸಾಮಾನ್ಯ ರೆಕಾರ್ಡಿಂಗ್ ಎರಡೂ ಆಡಿಯೊ ಟ್ರ್ಯಾಕ್‌ಗಳನ್ನು WAV ಆಗಿಯೂ, ಎರಡೂ ಉಪಶೀರ್ಷಿಕೆ ಟ್ರ್ಯಾಕ್‌ಗಳನ್ನು SRT ಆಗಿಯೂ ಉಳಿಸುತ್ತದೆ.

ಡೆಸ್ಕ್‌ಟಾಪ್ ಆ್ಯಪ್, Python, FFmpeg, localhost ಅಥವಾ ವರ್ಚುವಲ್ ಆಡಿಯೊ ಸಾಧನದ ಅಗತ್ಯವಿಲ್ಲದೆ ಈ ವಿಸ್ತರಣೆ ಸ್ವತಂತ್ರವಾಗಿ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತದೆ. ಪ್ರಸ್ತುತ ಇಂಟರ್‌ಫೇಸ್ ಇಂಗ್ಲಿಷ್, ಪರ್ಷಿಯನ್ ಮತ್ತು ಸರಳೀಕೃತ ಚೈನೀಸ್ ಭಾಷೆಗಳಲ್ಲಿ ಮಾತ್ರ ಲಭ್ಯವಿದೆ; ಅನುವಾದದ ಗುರಿ ಭಾಷೆಯನ್ನು 79 ಭಾಷಾ ಆಯ್ಕೆಗಳಿಂದ ಪ್ರತ್ಯೇಕವಾಗಿ ಆರಿಸಬಹುದು.

ಸೆಟಪ್: ಸೆಟ್ಟಿಂಗ್‌ಗಳಲ್ಲಿ Google AI Studio ನಿಂದ ಪಡೆದ ನಿಮ್ಮದೇ Gemini API ಕೀಲಿಯನ್ನು ನಮೂದಿಸಿ, ಆಯ್ದ ಟ್ಯಾಬ್‌ನ ಆಡಿಯೊವನ್ನು Google Gemini ಗೆ ಕಳುಹಿಸಲು ಸ್ಪಷ್ಟ ಒಪ್ಪಿಗೆ ನೀಡಿ, ಭಾಷೆಯನ್ನು ಆರಿಸಿ ಮತ್ತು Start ಒತ್ತಿರಿ. ಐಚ್ಛಿಕ ನಿಖರ ಮೋಡ್ ಲಿಪ್ಯಂತರಕ್ಕೆ Groq Whisper, ಪಠ್ಯ ಅನುವಾದಕ್ಕೆ Gemini ಮತ್ತು ಮಾತಿನ ಉತ್ಪಾದನೆಗೆ Gemini 3.1 Flash Live ಬಳಸುತ್ತದೆ. ಇದಕ್ಕೆ Groq ಕೀಲಿ, ಐಚ್ಛಿಕ ಹೋಸ್ಟ್ ಅನುಮತಿ ಮತ್ತು ಪ್ರತ್ಯೇಕ ಆಡಿಯೊ ಒಪ್ಪಿಗೆ ಅಗತ್ಯ.

ಗೌಪ್ಯತೆ: ಒಪ್ಪಿಗೆ ನೀಡಿ Start ಒತ್ತಿದ ನಂತರವೇ ಸೆರೆಹಿಡಿಯುವಿಕೆ ಆರಂಭವಾಗುತ್ತದೆ. ಆಯ್ದ ಟ್ಯಾಬ್‌ನ ಆಡಿಯೊ ಮತ್ತು ಲಿಪ್ಯಂತರಗಳು ನೀವು ವಿನಂತಿಸಿದ ಪ್ರಕ್ರಿಯೆಗೆ ಅಗತ್ಯವಿರುವ AI ಸೇವಾ ಪೂರೈಕೆದಾರರಿಗೆ ನೇರವಾಗಿ ಹೋಗುತ್ತವೆ; Avorythm ನಿರ್ವಹಣಾಕಾರರಿಗೆ ಎಂದಿಗೂ ಹೋಗುವುದಿಲ್ಲ. ಜಾಹೀರಾತುಗಳು, ವಿಶ್ಲೇಷಣಾ ಟ್ರ್ಯಾಕಿಂಗ್ ಅಥವಾ ಡೆವಲಪರ್ ನಡೆಸುವ ಮಧ್ಯವರ್ತಿ ಸರ್ವರ್ ಇಲ್ಲ.

API ಕೀಲಿಗಳು ಪೂರ್ವನಿಯೋಜಿತವಾಗಿ ಆ ಸೆಷನ್‌ಗೆ ಮಾತ್ರ ಸೀಮಿತವಾಗಿರುತ್ತವೆ. ಈ ಸಾಧನದಲ್ಲಿ ಪ್ರತಿ ಪೂರೈಕೆದಾರರ ಕೀಲಿಯನ್ನು ನೆನಪಿಟ್ಟುಕೊಳ್ಳುವ ಆಯ್ಕೆ ಪ್ರತ್ಯೇಕವಾಗಿದ್ದು, ಪೂರ್ವನಿಯೋಜಿತವಾಗಿ ಆಫ್ ಆಗಿರುತ್ತದೆ. ಸಂಗ್ರಹಿಸಿದ ಪ್ರತಿಗಳು ಸಿಂಕ್ ಆಗುವುದಿಲ್ಲ ಮತ್ತು ವಿಸ್ತರಣೆಯು ಅವನ್ನು ಎನ್‌ಕ್ರಿಪ್ಟ್ ಮಾಡುವುದಿಲ್ಲ. ನೆನಪಿಟ್ಟುಕೊಳ್ಳುವಿಕೆಯನ್ನು ಆಫ್ ಮಾಡಿದರೆ ಸಾಧನದಲ್ಲಿನ ಪ್ರತಿ ಅಳಿಸಲಾಗುತ್ತದೆ; ಕೀಲಿಯನ್ನು ತೆರವುಗೊಳಿಸಿದರೆ ಸಾಧನ ಮತ್ತು ಸೆಷನ್‌ನಲ್ಲಿನ ಎರಡೂ ಪ್ರತಿಗಳು ಅಳಿಸಲಾಗುತ್ತವೆ.

ನಾಲ್ಕು ಔಟ್‌ಪುಟ್‌ಗಳನ್ನು ಉಳಿಸುವ ಸಾಮಾನ್ಯ ರೆಕಾರ್ಡಿಂಗ್ ಪೂರ್ವನಿಯೋಜಿತವಾಗಿ ಆಫ್ ಆಗಿರುತ್ತದೆ. ಸಿಂಕ್ ಮಾಡಿದ ಮೋಡ್ ಪ್ಲೇಬ್ಯಾಕ್ ಮತ್ತು ರಫ್ತಿಗಾಗಿ ಸ್ಥಳೀಯವಾಗಿ ರೆಕಾರ್ಡ್ ಮಾಡುತ್ತದೆ ಹಾಗೂ ಇತ್ತೀಚಿನ ಸೆರೆಹಿಡಿದ ದಾಖಲೆಯನ್ನು ಮಾತ್ರ Chrome ನ ಖಾಸಗಿ ಸಂಗ್ರಹಣೆಯಲ್ಲಿ ಇಡುತ್ತದೆ. ಡೌನ್‌ಲೋಡ್ ಮಾಡಿದ ಫೈಲ್‌ಗಳು Downloads/Avorythm ಗೆ ಹೋಗುತ್ತವೆ.

Avorythm ಉಚಿತ ಮತ್ತು ಮುಕ್ತ ಮೂಲದ ಯೋಜನೆ. ಬಾಹ್ಯ AI ಸೇವೆಗಳ ಉಚಿತ ಬಳಕೆಯ ಮಿತಿಗಳು ಮತ್ತು ಮಾದರಿಗಳ ಲಭ್ಯತೆ ಬದಲಾಗಬಹುದು. ನೇರ ಪ್ರಕ್ರಿಯೆಗೆ ನೆಟ್‌ವರ್ಕ್ ಸಮಯ ಬೇಕಾಗುತ್ತದೆ; ಶೂನ್ಯ ವಿಳಂಬ ಅಥವಾ ಪರಿಪೂರ್ಣ ಅನುವಾದದ ಖಾತರಿ ಇಲ್ಲ. ಪ್ರಮುಖ ವಿಷಯವನ್ನು ಪರಿಶೀಲಿಸಿ. DRM ರಕ್ಷಿತ ಮಾಧ್ಯಮ ಮತ್ತು ಬ್ರೌಸರ್‌ನ ಆಂತರಿಕ ಪುಟಗಳಲ್ಲಿ ಸೆರೆಹಿಡಿಯುವಿಕೆ ಸಾಧ್ಯವಾಗದೇ ಇರಬಹುದು.
