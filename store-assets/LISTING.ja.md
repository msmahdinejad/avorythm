# Chrome Web Store — Japanese (ja)

## 名前

Avorythm — AIによるリアルタイム吹き替えと字幕

## 短い説明

選択したタブの音声をAIで翻訳。リアルタイム吹き替え、二言語字幕、同期プレーヤーを利用できます。

## 詳細な説明

講座や動画、映画を視聴したり、ポッドキャストを聴いたりするときに、希望する言語を使えます。Avorythm は、明示的に選択したブラウザータブの音声をAIで翻訳します。リアルタイムの吹き替えを聴く、元の言語と翻訳後の字幕を表示する、元の音声を残して翻訳だけを読む、といった使い方ができます。

元のページでの低遅延再生と、同期録画・プレーヤーを選べます。同期キャプチャは先行して進み、独立したプレーヤーでは一時停止、シーク、全画面表示が可能です。録画は手動で終了できます。

元の音声、吹き替え音声、元の言語の字幕、翻訳後の字幕という4つのチャンネルを個別に操作できます。両方の音声の音量を調整し、字幕表示の位置と大きさを変え、設定を反映したWebM動画と個別のSRT字幕を書き出せます。任意で有効にできる通常録画では、両方の音声トラックをWAV、両方の字幕トラックをSRTとして保存することもできます。

この拡張機能は、デスクトップアプリ、Python、FFmpeg、localhost、仮想オーディオデバイスを使わず、単独で動作します。現在のインターフェースは英語、ペルシア語、簡体字中国語に対応しています。翻訳先の言語は、79件の言語項目から別途選択します。

設定方法：Settings に Google AI Studio で取得したご自身の Gemini APIキーを入力し、選択したタブの音声を Google Gemini に送信することに明示的に同意してから、言語を選んで Start を押します。任意の高精度モードでは、文字起こしに Groq Whisper、テキスト翻訳に Gemini、音声生成に Gemini 3.1 Flash Live を使用します。このモードには Groq のキー、任意のホスト権限、別途の音声送信への同意が必要です。

プライバシー：キャプチャは、同意して Start を押した後にのみ始まります。選択したタブの音声と文字起こしは、要求された処理に必要なAIサービス提供元へ直接送信され、Avorythm の開発者には送信されません。広告、分析、開発者が運営する中継サーバーはありません。

APIキーは初期設定ではセッション中にのみ保持されます。各サービス提供元のキーをこのデバイスに保存するかどうかは個別に選択でき、初期設定では無効です。保存されたキーは同期されず、拡張機能によって暗号化されません。保存設定を無効にするとデバイス上のコピーが削除され、キーを消去するとデバイス上とセッション中の両方のコピーが削除されます。

4種類の出力を保存する通常録画は、初期設定では無効です。同期モードでは、再生と書き出しのためにローカルで録画し、Chrome の非公開ストレージには最新のキャプチャのみを保持します。ダウンロードしたファイルは Downloads/Avorythm に保存されます。

Avorythm は無料のオープンソースソフトウェアです。外部AIサービスの無料利用枠やモデルの提供状況は変わる場合があります。リアルタイム処理にはネットワーク通信の時間が必要で、遅延がゼロになることや翻訳が完全に正確であることは保証されません。重要な内容は確認してください。DRMで保護されたメディアやブラウザー内部のページでは、キャプチャできない場合があります。
