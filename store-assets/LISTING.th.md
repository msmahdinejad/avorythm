# Chrome Web Store — Thai (th)

## ชื่อ

Avorythm — พากย์สดและคำบรรยายด้วย AI

## คำอธิบายสั้น

แปลเสียงจากแท็บที่คุณเลือกด้วย AI พร้อมเสียงพากย์สด คำบรรยายสองภาษา และเครื่องเล่นที่ซิงก์กัน

## คำอธิบายโดยละเอียด

รับชมบทเรียน วิดีโอ และภาพยนตร์ หรือฟังพอดแคสต์ในภาษาของคุณ Avorythm ใช้ AI แปลเสียงจากแท็บเบราว์เซอร์ที่คุณเลือกเองอย่างชัดเจน คุณสามารถฟังเสียงพากย์สด ดูคำบรรยายภาษาต้นฉบับและภาษาแปล หรือฟังเสียงต้นฉบับพร้อมอ่านเฉพาะคำแปลก็ได้

เลือกเล่นแบบหน่วงต่ำบนหน้าเว็บต้นฉบับ หรือใช้เครื่องบันทึกและเครื่องเล่นที่ซิงก์กัน การบันทึกในโหมดซิงก์จะดำเนินไปล่วงหน้า ขณะที่เครื่องเล่นแยกต่างหากสามารถหยุดชั่วคราว เลื่อนไปยังตำแหน่งที่ต้องการ และแสดงเต็มหน้าจอได้ คุณสามารถสั่งสิ้นสุดการบันทึกเองได้

ควบคุมสี่ช่องได้อย่างอิสระ ได้แก่ เสียงต้นฉบับ เสียงพากย์ คำบรรยายภาษาต้นฉบับ และคำบรรยายภาษาแปล ปรับระดับเสียงทั้งสองช่อง เลื่อนและปรับขนาดคำบรรยายที่ซ้อนบนภาพ และส่งออกวิดีโอ WebM ที่ปรับแต่งแล้วพร้อมคำบรรยาย SRT แยกไฟล์ การบันทึกแบบปกติซึ่งเป็นตัวเลือกเพิ่มเติมยังบันทึกเสียงทั้งสองช่องเป็น WAV และคำบรรยายทั้งสองภาษาเป็น SRT ด้วย

ส่วนขยายนี้ทำงานได้ด้วยตัวเอง โดยไม่ต้องใช้แอปเดสก์ท็อป Python, FFmpeg, localhost หรืออุปกรณ์เสียงเสมือน อินเทอร์เฟซปัจจุบันรองรับภาษาอังกฤษ เปอร์เซีย และจีนตัวย่อ ส่วนภาษาเป้าหมายของการแปลเลือกแยกต่างหากได้จากรายการภาษา 79 รายการ

การตั้งค่า: ป้อนคีย์ Gemini API ของคุณเองจาก Google AI Studio ในหน้าการตั้งค่า ให้ความยินยอมอย่างชัดเจนในการส่งเสียงจากแท็บที่เลือกไปยัง Google Gemini เลือกภาษา แล้วกดเริ่ม โหมดแม่นยำซึ่งเป็นตัวเลือกเพิ่มเติมใช้ Groq Whisper ถอดเสียง ใช้ Gemini แปลข้อความ และใช้ Gemini 3.1 Flash Live สร้างเสียงพูด โหมดนี้ต้องใช้คีย์ Groq การอนุญาตให้เข้าถึงโฮสต์ซึ่งเป็นทางเลือก และความยินยอมในการส่งเสียงแยกต่างหาก

ความเป็นส่วนตัว: การจับเสียงจะเริ่มขึ้นหลังจากคุณให้ความยินยอมและกดเริ่มเท่านั้น เสียงจากแท็บที่เลือกและข้อความถอดเสียงจะส่งตรงไปยังผู้ให้บริการ AI ที่จำเป็นต่อการประมวลผลตามที่ร้องขอ โดยไม่ส่งไปยังผู้ดูแล Avorythm ไม่มีโฆษณา การวิเคราะห์ข้อมูล หรือเซิร์ฟเวอร์ส่งต่อที่ผู้พัฒนาดำเนินการ

โดยค่าเริ่มต้น คีย์ API จะถูกเก็บไว้เฉพาะในเซสชัน คุณสามารถเลือกให้จดจำคีย์ของผู้ให้บริการแต่ละรายบนอุปกรณ์นี้ได้แยกกัน โดยค่าเริ่มต้นจะปิดอยู่ สำเนาที่จัดเก็บจะไม่ซิงก์ และส่วนขยายจะไม่เข้ารหัสสำเนาเหล่านั้น การปิดการจดจำจะลบสำเนาบนอุปกรณ์ ส่วนการล้างคีย์จะลบทั้งสำเนาบนอุปกรณ์และในเซสชัน

การบันทึกแบบปกติที่ได้ผลลัพธ์สี่รายการปิดอยู่โดยค่าเริ่มต้น โหมดซิงก์จะบันทึกไว้ในเครื่องเพื่อเล่นและส่งออก โดยเก็บเฉพาะข้อมูลที่บันทึกล่าสุดไว้ในพื้นที่จัดเก็บส่วนตัวของ Chrome ไฟล์ที่ดาวน์โหลดจะอยู่ใน Downloads/Avorythm

Avorythm ใช้งานได้ฟรีและเป็นโอเพนซอร์ส โควตาฟรีและความพร้อมใช้งานของโมเดลจากบริการ AI ภายนอกอาจเปลี่ยนแปลงได้ การประมวลผลสดต้องใช้เวลาในการรับส่งข้อมูลผ่านเครือข่าย จึงไม่รับประกันว่าจะไม่มีความหน่วงหรือแปลได้สมบูรณ์แบบ โปรดตรวจสอบเนื้อหาที่สำคัญ สื่อที่มีการป้องกันด้วย DRM และหน้าภายในของเบราว์เซอร์อาจทำให้จับเสียงไม่ได้
