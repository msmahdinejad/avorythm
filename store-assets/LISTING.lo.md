# Chrome Web Store — Lao (lo)

## ຊື່

Avorythm — ພາກສຽງສົດ ແລະ ຄຳບັນຍາຍດ້ວຍ AI

## ຄຳອະທິບາຍສັ້ນ

ໃຊ້ AI ແປສຽງຈາກແທັບທີ່ທ່ານເລືອກ: ພາກສຽງສົດ, ຄຳບັນຍາຍສອງພາສາ ແລະ ເຄື່ອງຫຼິ້ນທີ່ຊິງກັບສຽງ.

## ຄຳອະທິບາຍໂດຍລະອຽດ

ເບິ່ງບົດຮຽນ, ວິດີໂອ ແລະ ຮູບເງົາ ຫຼື ຟັງພອດແຄສເປັນພາສາຂອງທ່ານ. Avorythm ໃຊ້ AI ແປສຽງຈາກແທັບໃນເບຣົາເຊີທີ່ທ່ານເລືອກຢ່າງຊັດເຈນ. ທ່ານສາມາດຟັງສຽງພາກສົດ, ເບິ່ງຄຳບັນຍາຍພາສາຕົ້ນສະບັບແລະພາສາແປ, ຫຼື ຟັງສຽງຕົ້ນສະບັບໂດຍອ່ານພຽງຄຳແປ.

ເລືອກການຫຼິ້ນທີ່ໜ່ວງເວລາຕ່ຳໃນໜ້າເດີມ ຫຼື ໃຊ້ເຄື່ອງບັນທຶກແລະເຄື່ອງຫຼິ້ນທີ່ຊິງກັນ. ການຈັບພາບແລະສຽງແບບຊິງກັນຈະດຳເນີນໄປລ່ວງໜ້າ, ຂະນະທີ່ເຄື່ອງຫຼິ້ນແຍກຕ່າງຫາກສາມາດຢຸດຊົ່ວຄາວ, ເລື່ອນໄປຍັງຈຸດທີ່ຕ້ອງການ ແລະ ສະແດງເຕັມຈໍໄດ້. ທ່ານສາມາດສັ່ງສິ້ນສຸດການບັນທຶກເອງໄດ້.

ຄວບຄຸມ 4 ຊ່ອງທາງໄດ້ແຍກກັນ: ສຽງຕົ້ນສະບັບ, ສຽງພາກ, ຄຳບັນຍາຍພາສາຕົ້ນສະບັບ ແລະ ຄຳບັນຍາຍພາສາແປ. ປັບລະດັບສຽງທັງສອງໃຫ້ປະສົມກັນ, ຍ້າຍແລະປັບຂະໜາດຄຳບັນຍາຍທີ່ຊ້ອນເທິງພາບ, ແລະ ສົ່ງອອກວິດີໂອ WebM ຕາມທີ່ປັບແຕ່ງ ພ້ອມໄຟລ໌ຄຳບັນຍາຍ SRT ແຍກຕ່າງຫາກ. ການບັນທຶກແບບປົກກະຕິທີ່ເປັນທາງເລືອກ ຍັງບັນທຶກສຽງທັງສອງຊ່ອງເປັນ WAV ແລະ ຄຳບັນຍາຍທັງສອງຊ່ອງເປັນ SRT.

ສ່ວນຂະຫຍາຍນີ້ໃຊ້ງານໄດ້ໂດຍອິດສະຫຼະ ໂດຍບໍ່ຕ້ອງມີແອັບເດັສກ໌ທັອບ, Python, FFmpeg, localhost ຫຼື ອຸປະກອນສຽງສະເໝືອນ. ປັດຈຸບັນ ສ່ວນຕິດຕໍ່ຜູ້ໃຊ້ມີພຽງພາສາອັງກິດ, ເປີເຊຍ ແລະ ຈີນຕົວຫຍໍ້; ພາສາປາຍທາງສຳລັບການແປເລືອກໄດ້ແຍກຕ່າງຫາກຈາກ 79 ລາຍການພາສາ.

ການຕັ້ງຄ່າ: ປ້ອນຄີ API ຂອງ Gemini ທີ່ທ່ານໄດ້ຈາກ Google AI Studio ໃນໜ້າການຕັ້ງຄ່າ, ໃຫ້ຄວາມຍິນຍອມຢ່າງຊັດເຈນໃນການສົ່ງສຽງຈາກແທັບທີ່ເລືອກໄປຫາ Google Gemini, ເລືອກພາສາ ແລ້ວກົດ Start. ໂໝດຄວາມແມ່ນຍຳສູງທີ່ເປັນທາງເລືອກ ໃຊ້ Groq Whisper ເພື່ອຖອດສຽງເປັນຂໍ້ຄວາມ, Gemini ເພື່ອແປຂໍ້ຄວາມ ແລະ Gemini 3.1 Flash Live ເພື່ອສ້າງສຽງເວົ້າ. ໂໝດນີ້ຕ້ອງໃຊ້ຄີຂອງ Groq, ອາດຕ້ອງໃຫ້ສິດເຂົ້າເຖິງໂຮສທີ່ເປັນທາງເລືອກ ແລະ ຕ້ອງໃຫ້ຄວາມຍິນຍອມສຳລັບສຽງແຍກຕ່າງຫາກ.

ຄວາມເປັນສ່ວນຕົວ: ການຈັບສຽງເລີ່ມຂຶ້ນຫຼັງຈາກທ່ານໃຫ້ຄວາມຍິນຍອມແລະກົດ Start ເທົ່ານັ້ນ. ສຽງຈາກແທັບທີ່ເລືອກແລະຂໍ້ຄວາມທີ່ຖອດຈາກສຽງຈະຖືກສົ່ງໂດຍກົງໄປຫາຜູ້ໃຫ້ບໍລິການ AI ທີ່ຈຳເປັນຕໍ່ການປະມວນຜົນທີ່ທ່ານຮ້ອງຂໍ ແລະ ບໍ່ສົ່ງໄປຫາຜູ້ດູແລ Avorythm. ບໍ່ມີໂຄສະນາ, ການວິເຄາະຂໍ້ມູນ ຫຼື ເຊີບເວີສົ່ງຕໍ່ທີ່ຜູ້ພັດທະນາດຳເນີນການ.

ໂດຍຄ່າເລີ່ມຕົ້ນ ຄີ API ຈະຖືກເກັບໄວ້ສະເພາະໃນເຊດຊັນ. ການຈື່ຈຳຄີຂອງແຕ່ລະຜູ້ໃຫ້ບໍລິການໃນອຸປະກອນນີ້ເປັນທາງເລືອກແຍກກັນ ແລະ ປິດໄວ້ໂດຍຄ່າເລີ່ມຕົ້ນ. ຄີທີ່ເກັບໄວ້ຈະບໍ່ຖືກຊິງຂໍ້ມູນ ແລະ ສ່ວນຂະຫຍາຍບໍ່ໄດ້ເຂົ້າລະຫັດຄີເຫຼົ່ານັ້ນ. ການປິດການຈື່ຈຳຈະລຶບສຳເນົາຄີໃນອຸປະກອນ; ການລ້າງຄີຈະລຶບທັງສຳເນົາໃນອຸປະກອນແລະໃນເຊດຊັນ.

ການບັນທຶກແບບປົກກະຕິທີ່ໄດ້ຜົນລັບ 4 ຢ່າງ ປິດໄວ້ໂດຍຄ່າເລີ່ມຕົ້ນ. ໂໝດຊິງກັນຈະບັນທຶກຂໍ້ມູນໃນອຸປະກອນເພື່ອໃຊ້ຫຼິ້ນແລະສົ່ງອອກ ແລະ ເກັບໄວ້ພຽງການຈັບພາບແລະສຽງຄັ້ງລ່າສຸດໃນບ່ອນເກັບຂໍ້ມູນສ່ວນຕົວຂອງ Chrome. ໄຟລ໌ທີ່ດາວໂຫຼດຈະຢູ່ໃນ Downloads/Avorythm.

Avorythm ໃຊ້ໄດ້ຟຣີ ແລະ ເປັນຊອບແວເປີດເຜີຍລະຫັດຕົ້ນສະບັບ. ໂຄຕ້າການໃຊ້ງານຟຣີແລະຄວາມພ້ອມໃຫ້ໃຊ້ຂອງໂມເດວໃນບໍລິການ AI ພາຍນອກອາດປ່ຽນແປງໄດ້. ການປະມວນຜົນສົດຕ້ອງໃຊ້ເວລາຜ່ານເຄືອຂ່າຍ ແລະ ບໍ່ຮັບປະກັນວ່າຈະບໍ່ມີຄວາມໜ່ວງເລີຍ ຫຼື ແປໄດ້ຖືກຕ້ອງສົມບູນ; ຄວນກວດສອບເນື້ອຫາທີ່ສຳຄັນ. ສື່ທີ່ປ້ອງກັນດ້ວຍ DRM ແລະ ໜ້າພາຍໃນຂອງເບຣົາເຊີອາດຂັດຂວາງການຈັບພາບແລະສຽງ.

## ມີຫຍັງໃໝ່ໃນ 1.1.15

- ເລືອກພາສາໄດ້ງ່າຍຂຶ້ນ: ພາສາທີ່ນິຍົມຢູ່ກ່ອນ ພ້ອມການແຍກຮູບແບບພາສາຈີນແລະພາສາປອກຕຸຍການຢ່າງຊັດເຈນ.
- ເພີ່ມເອກະສານໂຄງການແລະຊັບພະຍາກອນໃໝ່ເປັນພາສາເຢຍລະມັນ, ຝຣັ່ງ, ອິຕາລີ, ລັດເຊຍ ແລະ ອາຣັບ.
- ປັບປຸງຮູບພາບໃນຮ້ານຄ້າ ໂດຍອີງຕາມສ່ວນຕິດຕໍ່ຜູ້ໃຊ້ຈິງຂອງຜະລິດຕະພັນ.
